# Image-Query Relevance Matching

Проект для оценки релевантности пар image-query с использованием deep learning и машинного обучения.

## Описание

Система обучается на размеченных экспертами парах изображение-запрос и предсказывает степень соответствия между ними в диапазоне [0, 1].

## Структура проекта

```
.
├── train_images/          # Тренировочные изображения
├── test_images/           # Тестовые изображения
├── notebooks/
│   └── main_notebook.ipynb    # Основной ноутбук проекта
├── data/
│   ├── ExpertAnnotations.tsv      # Оценки трёх экспертов
│   ├── CrowdAnnotations.tsv       # Краудсорсинг оценки
│   ├── train_dataset.csv          # Тренировочные пары
│   ├── test_queries.csv           # Тестовые запросы
│   ├── test_images.csv            # Информация о тестовых изображениях
│   ├── image_features.pkl         # Извлеченные признаки изображений (ResNet18, размер 512)
│   └── text_features.pkl          # Извлеченные текстовые признаки (BERT, размер 768)
├── models/
│   ├── image_features.pkl         # Сохраненные признаки всех изображений
│   └── text_features.pkl          # Сохраненные текстовые признаки
├── README.md              # Этот файл
├── requirements.txt       # Зависимости проекта
└── .gitignore            # Git конфигурация
```

## Технологический стек

- **PyTorch** - глубокое обучение
- **Transformers (HuggingFace)** - BERT для текстовых признаков
- **TorchVision** - ResNet18 для признаков изображений
- **XGBoost, LightGBM, scikit-learn** - машинное обучение
- **Pandas, NumPy** - обработка данных
- **Matplotlib, Seaborn** - визуализация

## Основные этапы

###  Анализ данных
- **5822** пар в тренировочном наборе (5696 после очистки)
- **500** пар в тестовом наборе
- Оценки трёх экспертов с корреляцией 0.79-0.89
- Краудсорсинг данные (менее надежны)

### Предварительная обработка
- Удаление пар с детским контентом (потеря 2%)
- Нормализация экспертных оценок в диапазон [0, 1]
- Исключение 2.2% конфликтов (все три эксперта дали разные оценки)

### Векторизация

#### Признаки изображений
- Модель: **ResNet18** (pretrained на ImageNet)
- Размер вектора: **512**
- Обработано: **1100** уникальных изображений

#### Текстовые признаки
- Модель: **BERT** (bert-base-uncased)
- Размер вектора: **768**
- Обработано: **707** уникальных запросов

#### Комбинированные признаки
- Размер: **1280** (512 + 768)

### бучение моделей

Обучены 10 моделей на комбинированных признаках:

| Место | Модель | Spearman | MAE |
|-------|--------|----------|-----|
| 1️⃣1| SVR (RBF) | **0.4199** | 0.185 |
| 2️⃣ | LightGBM | 0.3990 | 0.191 |
| 3️⃣ | XGBoost | 0.3958 | 0.193 |
| 4️⃣ | GradientBoosting | 0.3920 | 0.195 |
| 5️⃣ | ExtraTrees | 0.3835 | 0.198 |

**Лучшая модель:** SVR с радиальным ядром (Spearman: 0.4199)

### Тестирование

- Предсказания на 500 тестовых парах
- Визуализация 10 случайных примеров с лучшими запросами
- Анализ распределения предсказаний

## Результаты

**Распределение целевой переменной (target):**
- 41.3% - не совпадают (target = 0)
- 29.0% - слабо совпадают (0-0.33)
- 23.0% - хорошо совпадают (0.33-0.67)
- 6.7% - идеально совпадают (>0.67)

**Качество модели:**
- Корреляция Спирмена: 0.42
- Средняя абсолютная ошибка (MAE): 0.185

## Основной ноутбук

Ноутбук `main_notebook.ipynb` содержит:

1. **Загрузка и анализ данных**
   - Чтение ExpertAnnotations и CrowdAnnotations
   - Статистика оценок и согласованность экспертов
   - Визуализация распределений

2. **Предварительная обработка**
   - Фильтрация детского контента
   - Нормализация целевой переменной
   - Разделение на тренировочный и валидационный наборы

3. **Извлечение признаков**
   - Загрузка предобученных моделей (ResNet18, BERT)
   - Обработка всех изображений и запросов
   - Комбинирование признаков

4. **Обучение и оценка моделей**
   - 10 различных моделей ML
   - Сравнение по Spearman, MAE, MSE, R²
   - Выбор лучшей модели

5. **Тестирование и визуализация**
   - Предсказания на тестовом наборе
   - Визуализация результатов
   - Анализ качества
